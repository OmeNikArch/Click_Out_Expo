# Click Out — материал для выставок сентября–октября 2026

Презентация направления Click Out для потенциальных клиентов на выставках.
Показывается с планшета у стенда, ведёт разговор Никита.

## Базовая презентация

- `index.html` — **клиентская версия**. Эту ссылку можно давать клиенту.
- `presenter.html` — **версия ведущего**: тот же материал плюс суфлёр
  (что говорить на каждом экране, границы честности, нормы дня) и форма-опросник,
  которая отправляет строку в общую Google-таблицу.
  Суфлёр включается кнопкой в углу или клавишей `S`. Клиенту не показывать.
- `script.html` — скрипт работы на выставке: подход, выход на ЛПР, возражения, закрытие.

## Презентации под конкретные выставки

Оглавление — `events.html`. Каждая выставка — клон `presenter.html`, адаптированный под нишу площадки,
с элементами предварительного аудита (ниша в цифрах, сегменты по Ozon / Urban Ads / WB, бенчмарки,
чек-лист аудита, кейсы под нишу, смежные направления Церебро) и опросником.

| Выставка | Даты | Ведущему (суфлёр + форма) | Клиенту |
|---|---|---|---|
| WorldFood Moscow | 15–18.09 | `worldfood/presenter.html` | `worldfood/index.html` |
| Дентал-Экспо | 21–24.09 | `dental-expo/presenter.html` | `dental-expo/index.html` |
| ПаркЗоо | 23–25.09 | `parkzoo/presenter.html` | `parkzoo/index.html` |
| BUYBRAND Expo | 29.09–01.10 | `buybrand/presenter.html` | `buybrand/index.html` |

В форме каждой презентации выставка выбрана заранее, черновик хранится в браузере отдельно для каждой
страницы. Блок «Экспресс-квалификация у стенда» (кто это, сайт, бюджет, роль собеседника) дописывается
к полю «Ниша» одной строкой — структура строки в таблице не меняется.

### Как править и пересобирать

Контент — `events/data.py` (по одному словарю на выставку), шаблон — `events/build.py`.

```bash
python3 events/build.py     # пересобирает <slug>/presenter.html, <slug>/index.html и events.html
```

PDF для показа без интернета:

```bash
google-chrome --headless=new --disable-gpu --no-sandbox --hide-scrollbars \
  --run-all-compositor-stages-before-draw --virtual-time-budget=12000 \
  --no-pdf-header-footer --print-to-pdf=worldfood.pdf file://$PWD/worldfood/presenter.html
```

Все страницы `noindex`. Методика вопросов — ТРИЗ в продажах (А. Кожемяко), полный опросник из 15 вопросов:
https://omenikarch.github.io/qnr-page/ · шаблон аудита: https://omenikarch.github.io/Preliminary_audit/
